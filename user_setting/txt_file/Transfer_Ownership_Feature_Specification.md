# 功能说明文档：转移所有权

- **功能名称**: 转移项目所有权
- **功能 ID**: FEAT-OWNER-TRANSFER
- **版本**: 1.0
- **创建日期**: 2025-11-28
- **作者**: Gemini

---

## 1. 功能概述

“转移所有权”功能允许当前的项目负责人（Owner）将其所有权和最高管理权限转让给团队中的另一位成员。此操作是敏感且不可逆的，因此需要通过多步验证来确保操作的安全性。

该功能主要通过一个多步骤的对话框完成。

## 2. 用户流程与界面

### 触发方式

用户在“成员管理”页面的某个指定位置（例如，在自己的用户信息旁）点击“转移所有权”按钮，以触发此流程。

### 步骤 1：选择新的负责人并确认风险

当对话框打开时，用户将看到以下界面：

- **对话框标题**: "转移所有权"，并带有一个皇冠图标（<Crown />）。
- **描述**: "将项目负责人权限转移给其他成员，此操作不可撤销"。
- **风险提示区**:
    - 一个带有警告三角形图标（<AlertTriangle />）的黄色高亮区域。
    - 明确告知用户转移所有权后的三大后果：
        1.  您的角色将自动降为管理员。
        2.  新项目负责人将拥有最高权限。
        3.  此操作无法撤销。
- **选择新的项目负责人**:
    - 一个下拉选择器（`<Select>`），标签为 "选择新的项目负责人"。
    - 下拉列表中包含所有可选的团队成员。每个选项应显示成员的**姓名**、**电子邮件**和**当前角色**。
    - 只有项目内的成员才能被选为新的负责人。
- **操作按钮**:
    - **取消**: 关闭对话框，所有状态重置。
    - **下一步**: 验证是否已选择成员。如果未选择，弹出错误提示 "请选择新的项目负责人"；如果已选择，则进入步骤 2。

### 步骤 2：安全验证

为了确认操作者是合法用户，此步骤要求进行身份验证：

- **安全提示**: "为确保安全，请完成以下验证"。
- **输入字段**:
    1.  **账号密码**:
        - 标签: "账号密码"。
        - 输入框类型: 密码（`type="password"`）。
        - 占位符: "输入您的密码"。
        - *（Demo Note: 提示用户测试密码为 "demo123"）*
    2.  **验证码**:
        - 标签: "验证码"。
        - 输入框与按钮组合:
            - 左侧是输入框，占位符: "输入验证码"。
            - 右侧是 "发送验证码" 按钮。点击后应向用户的注册邮箱或手机发送验证码。
        - *（Demo Note: 提示用户测试验证码为 "123456"）*
- **操作按钮**:
    - **上一步**: 返回步骤 1 的界面，保留已选择的成员。
    - **确认转移**:
        - 验证密码和验证码是否已填写。
        - 如果任一字段为空，弹出相应错误提示（"请输入密码" 或 "请输入验证码"）。
        - 验证密码和验证码的正确性。如果错误，弹出提示（"密码错误" 或 "验证码错误"）。
        - 验证通过后，执行所有权转移操作。

## 3. 交互逻辑与状态管理

- **对话框状态 (`open`)**: 通过 `open` 和 `onOpenChange` props 控制对话框的显示与隐藏。
- **步骤状态 (`step`)**: 使用 `useState` 管理当前所在的步骤（1 或 2）。
- **数据状态**:
    - `selectedMember`: 存储所选新负责人的 ID。
    - `password`: 存储用户输入的密码。
    - `verificationCode`: 存储用户输入的验证码。
- **关闭/取消逻辑**:
    - 点击 "取消" 按钮、"上一步" 按钮返回步骤 1，或点击对话框外部遮罩层时，应重置所有内部状态（`step`, `selectedMember`, `password`, `verificationCode`），确保下次打开时是初始状态。

## 4. 成功与失败场景

### 成功场景

1.  用户完成所有验证步骤，点击 "确认转移"。
2.  系统后端成功更新项目负责人。
3.  前端弹出成功提示，例如 "所有权转移成功"。
4.  对话框自动关闭。
5.  界面上的相关信息（例如成员列表中的角色）应刷新，以反映所有权的变更（原负责人降级为管理员，新负责人变为 Owner）。

### 失败/错误处理场景

- **未选择成员**: 点击 "下一步" 时，如果 `selectedMember` 为空，显示 `toast.error('请选择新的项目负责人')`。
- **未填写验证信息**: 点击 "确认转移" 时，如果 `password` 或 `verificationCode` 为空，显示相应的错误提示。
- **验证信息错误**:
    - 如果密码不正确，显示 `toast.error('密码错误')`。
    - 如果验证码不正确，显示 `toast.error('验证码错误')`。
- **API 调用失败**: 在实际执行转移操作时，如果后端返回错误，应向用户显示一个通用的失败提示，例如 "所有权转移失败，请稍后重试"。
