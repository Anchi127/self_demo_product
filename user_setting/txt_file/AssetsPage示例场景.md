## 二、通过 AI 指令触发的场景

在左侧 **AI Console** 输入框输入以下指令：

### 场景 1：开户（Create Account）

**触发指令示例**：
- `开户`
- `create`
- `帮我开户`
- `开一个 TikTok 账户`
- `开 Google 账户`
- `开 Meta 账户`

**效果**：
- 自动识别平台（默认 TikTok，可识别 Google/Meta）
- 在"进行中的工单"文件夹下创建开户草稿节点
- 自动跳转到开户表单视图
- AI 回复："已为您创建了 [平台] 开户草稿，请在右侧填写详细信息。"

### 场景 2：充值（Top-up）

**触发指令示例**：
- `充值`
- `加款`
- `充值 500`
- `充值 1000`
- `给账户充值`

**效果**：
- 自动提取金额（如未指定，默认 $1000）
- 创建充值工单节点（如："资金充值单 - $500"）
- 自动跳转到充值确认视图
- AI 回复："已生成 $[金额] 的充值工单，请确认充值对象和支付方式。"

### 场景 3：商务中心绑定（BC Binding）

**触发指令示例**：
- `绑定`
- `bind`
- `绑定商务中心`
- `建立绑定关系`

**效果**：
- 创建绑定任务节点（"商务中心绑定任务"）
- 自动跳转到绑定任务视图
- AI 回复："已建立绑定任务，请选择需要关联的账户和商务中心。"

### 场景 4：查看简报

**触发指令示例**：
- `简报`
- `概览`
- `查看简报`

**效果**：
- 切换回简报视图
- AI 回复："已切换至今日智能简报视图。"

## 三、通过 GUI 交互触发的场景

### 场景 1：从简报一键充值

**位置**：简报视图的风险预警卡片

**操作**：点击"一键补充预算"按钮

**效果**：自动触发 `processIntent('给余额不足账户充值 1000')`，创建 $1000 的充值工单

### 场景 2：从账户详情快捷操作

**位置**：账户详情视图底部的"快捷操作"区域

**操作**：
- 点击"充值"按钮 → 触发 `processIntent('给 [账户名] 充值')`
- 点击"商务绑定"按钮 → 触发 `processIntent('绑定 [账户名]')`

**效果**：自动创建对应的工单并跳转

### 场景 3：消息关联跳转

**位置**：AI 消息中的"查看详情"链接

**操作**：点击消息中的"查看详情 →"链接

**效果**：自动跳转到相关节点（如新创建的工单）

## 六、技术实现说明

### 意图识别引擎

所有 AI 指令通过 `processIntent()` 函数处理，支持：
- 关键词匹配（不区分大小写）
- 金额自动提取（正则表达式：`/\d+/`）
- 平台自动识别（TikTok/Google/Meta）
- 自动创建树节点
- 自动跳转视图

### 树节点管理

- **插入节点**：`insertNode()` - 递归插入到指定父节点
- **更新节点**：`updateTree()` - 递归更新节点属性
- **查找节点**：`findNode()` - 递归查找节点

### 视图渲染

根据 `selectedNode.type` 动态渲染：
- `briefing` → 智能简报视图
- `draft_account` → 开户草稿视图
- `topup_order` → 充值工单视图
- `binding_task` → 绑定任务视图
- `account` → 账户详情视图

## 七、数据模型

### TreeNode 结构
```typescript
{
  id: string;              // 唯一标识
  parentId: string | null; // 父节点ID
  label: string;           // 显示名称
  type: NodeType;          // 节点类型
  data?: NodeData;         // 节点数据
  children?: TreeNode[];   // 子节点
  isExpanded?: boolean;    // 是否展开
}
```

### NodeData 结构
```typescript
{
  balance?: number;           // 余额
  platform?: 'TikTok' | 'Google' | 'Meta';  // 平台
  status?: 'Active' | 'Reviewing' | 'Disabled' | 'Draft';  // 状态
  amount?: number;            // 充值金额
  targetAccountIds?: string[]; // 目标账户ID列表
  bindingTarget?: string;     // 绑定目标
  stats?: {                    // 统计数据
    lowBalanceCount: number;
    bannedCount: number;
    totalSpend: number;
  };
}
```

## 八、注意事项

1. **金额提取**：如果指令中未指定金额，充值功能默认使用 $1000
2. **平台识别**：开户功能默认创建 TikTok 账户，除非指令中包含 "google" 或 "meta"
3. **节点生成**：所有动态创建的节点都会添加到"进行中的工单"文件夹
4. **自动跳转**：创建新节点后会自动选中并跳转到对应视图
5. **消息关联**：AI 回复中包含 `relatedNodeId` 时会显示"查看详情"链接
