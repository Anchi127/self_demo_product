## 2. 开户管理

### 二级功能页：开户申请

| 功能点 | 使用场景 | 使用者 | 可解决的问题 |
| :--- | :--- | :--- | :--- |
| **在线发起各媒体开户**<br>(Meta/TikTok/Google/Snapchat/Kwai/Bing/X/Bigo/Taboola) | 为新客户或新项目申请广告账户，填写信息并生成记录。 | 账户运营 | 开户流程繁琐，申请周期长。 |
| **查看各媒体开户指引**<br>(Meta/TikTok/Google) | 学习并规范填写开户所需资料。 | 账户运营 | 不熟悉开户要求，导致申请被拒。 |

### 二级功能页：开户记录

| 功能点 | 使用场景 | 使用者 | 可解决的问题 |
| :--- | :--- | :--- | :--- |
| **筛选、查询开户记录列表** | 快速定位特定条件的开户申请。 | 账户运营 | 开户记录多，查找特定记录困难。 |
| **查看开户记录明细** | 核对开户资料，追踪申请状态。 | 账户运营 | 无法追溯开户详情，问题排查难。 |
| **查看已下户的账户名称和ID** | 获取成功开通的账户信息，用于投放。 | 广告优化师、账户运营 | 下户信息同步不及时，影响投放启动。 |
| **复制记录生成新草稿** | 快速创建和已有申请相似的新开户申请。 | 账户运营 | 重复填写相似信息，效率低下。 |
| **导出开户记录** | 批量整理开户数据，用于内部汇报或归档。 | 财务人员、账户运营 | 数据整理工作量大，易出错。 |

## 3. 广告账户

### 二级功能页：账户管理

| 功能点 | 使用场景 | 使用者 | 可解决的问题 |
| :--- | :--- | :--- | :--- |
| **筛选、查询广告账户** | 从海量账户中快速定位目标账户。 | 账户运营、广告优化师 | 账户数量庞大，查找和管理不便。 |
| **查看账户基础信息** | 了解账户状态、余额、绑定关系等。 | 账户运营、广告优化师 | 账户信息分散，查看需多平台切换。 |
| **单个/批量刷新账户信息** | 更新账户状态，确保数据为最新。 | 账户运营 | 系统数据滞后，影响决策准确性。 |
| **单个/批量绑定或解绑资产**<br>(BC/BM/MCC) | 调整账户的资产归属或管理权限，统一资产管理。 | 账户运营 | 逐个操作效率低，流程不标准且有风险。 |
| **单个账户发起转账** | 将余额从A账户调至B账户，灵活使用资金。 | 财务人员、账户运营 | 跨账户资金调配不便，流程繁琐。 |
| **单个/批量账户发起清零** | 回收不常用或废弃账户的剩余资金。 | 财务人员、账户运营 | 废弃账户余额沉睡，造成资金浪费；逐个操作效率低。 |
| **单个/批量账户发起充值** | 为账户补充预算，保障投放或高效管理资金。 | 财务人员、账户运营、广告优化师 | 充值流程不统一，记录缺失；批量操作繁琐。 |
| **单个账户发起减款** | 回收账户部分余额。 | 财务人员、账户运营 | 资金划转需求多样，操作流程不统一。 |
| **单个账户发起更名** | 修改账户名以符合内部命名规范。 | 账户运营 | 账户命名不规范，管理识别困难。 |
| **导出账户基础信息** | 获取账户清单，用于审计或数据分析。 | 财务人员、账户运营 | 手动整理账户信息，耗时且易遗漏。 |
| **消耗数据高级报表申请/查看** | 申请或查看广告消耗数据明细报表。 | 广告优化师 | 基础报表无法满足深度分析需求。 |
| **查看账户操作类工单记录** | 跟踪所有账户操作申请的进度和结果。 | 账户运营、广告优化师 | 操作进度不透明，需人工反复确认。 |
| **筛选/查询工单记录** | 快速定位特定类型或状态的操作工单。 | 账户运营 | 工单记录多，查找历史记录困难。 |
| **导出资金操作工单记录** | 导出充值、减款、清零记录，便于财务对账。 | 财务人员、账户运营 | 财务对账数据获取不便，效率低。 |
| **修改与提交被驳回工单** | 根据驳回意见修改并重新提交工单。 | 账户运营 | 工单被驳回后，修改和提交流程混乱。 |

### 二级功能页：账户充值

| 功能点 | 使用场景 | 使用者 | 可解决的问题 |
| :--- | :--- | :--- | :--- |
| **选择账户发起充值** | 为单个或多个账户快速发起充值申请。 | 账户运营、广告优化师 | 充值入口分散，操作路径长。 |
| **Excel批量导入充值** | 根据表格批量为多个账户发起充值。 | 财务人员、账户运营 | 大规模账户充值，手动操作不现实。 |
| **查看充值工单记录** | 查看所有充值申请的处理状态和详情。 | 财务人员、账户运营 | 充值进度不透明，影响资金安排。 |

| 功能点 | 使用场景 | 使用者 | 可解决的问题 |
| :--- | :--- | :--- | :--- |
